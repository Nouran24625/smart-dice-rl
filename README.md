# Smart Dice Board Game: Reinforcement Learning

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/Nouran24625/smart-dice-rl/blob/main/SmartDice_RL.ipynb)

An agent learns to play a snakes-and-ladders board game in which it **chooses the dice value (1–6)** every turn. Five reinforcement-learning agents are trained and compared against two exact references on boards of 30, 50, 100 and 200 squares.

**Author:** Nouran Ahmed Ahmed Ali Elshikh (ID 320230066). Reinforcement Learning course project.

| Agent | Family | Implementation |
|---|---|---|
| Q-Learning | Tabular, off-policy TD | from scratch (NumPy) |
| SARSA | Tabular, on-policy TD | from scratch (NumPy) |
| DQN | Deep RL, value-based | [stable-baselines3](https://stable-baselines3.readthedocs.io) |
| PPO | Deep RL, policy gradient | stable-baselines3 |
| A2C | Deep RL, actor-critic | stable-baselines3 |
| BFS | Exact shortest game (reference) | plain Python |
| Value iteration (Q\*) | Exact highest-return policy (reference) | NumPy |

## What's inside

Everything is in one notebook, [`SmartDice_RL.ipynb`](SmartDice_RL.ipynb). Each code cell is preceded by an explanation of what it does and why.

1. **MDP formulation** and documented design decisions (invalid moves, episode limit, observation encoding)
2. **A custom Gymnasium environment**, `SmartDiceEnv`, tested by hand and with SB3's `check_env`
3. **Seeded board generator** (no chains, guaranteed solvable) and a board renderer
4. **Baselines:** random, "always 6", BFS
5. **Q-Learning and SARSA** from scratch, graded against both BFS and value iteration
6. **DQN, PPO and A2C** with stable-baselines3, evaluated with the same metrics
7. **A comparison of all five agents** against environment steps
8. **Advanced challenges:** reward design (including a reward-hacking loop), random dice, and a 200-square board
9. **An interactive board explorer:** play any agent's game move by move and inspect every square's policy
10. **Report:** answers to the ten project questions and the research question

## Key findings

All numbers come from the notebook and are reproducible (fixed seeds). The full tables are in [`results/RESULTS.md`](results/RESULTS.md), which the notebook generates.

- **Both tabular agents learn the exact optimal game** (4 / 5 / 6 moves on boards 30 / 50 / 100, matching BFS and value iteration) on every seed.
- **SARSA with a constant learning rate never fully settles.** Its update target uses the next action it actually takes, which is sometimes random, so its greedy policy keeps flipping between near-equal routes. A decaying learning rate makes it 100% stable.
- **The brief's reward table sits just below a reward-hacking threshold.** Raising the ladder reward from +20 to +23 (board 30) or +24 (board 100) makes the optimal policy loop ladder → snake → ladder forever instead of finishing.
- **DQN reaches the optimum on every board and seed and ends with the best whole policy** (93–100% of squares optimal), but needs 3–30× more environment steps than Q-Learning. PPO is optimal on 8/9 seeds; A2C on 6/9, and it never reaches the optimum on the 100-square board.
- **Success rate cannot measure learning here:** even a random agent finishes 100% of games within the move limit. Agents are compared on moves vs. the optimum, return, and the share of squares where they choose an optimal dice value.
- **With random dice (two dice rolled, choose one), BFS no longer applies.** RL learns a near-optimal policy from play alone. This answers the project's research question.

## Run it

**Google Colab (recommended):** click the badge above, then *Runtime → Run all*. The first cell installs `gymnasium` and `stable-baselines3`. A full run takes about 45 minutes on a free CPU runtime, most of it deep-RL training. On Colab, results are saved to Google Drive, and every finished run is reused, so after a disconnect just run all again and it continues where it stopped.

**Locally:**

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab SmartDice_RL.ipynb
```
